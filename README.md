### 📌 Featured Projects

**🫀 [Coronary Angiogram Analysis & Segmentation System](#)**
Zero-shot coronary artery segmentation using the Segment Anything Model (SAM) with custom prompt engineering, morphological stenosis quantification, and an interactive clinical validation GUI. *(PyTorch, SAM, OpenCV, Scikit-Image)*

**🩻 [AI-Powered Medical Image Analysis Tool](#)**
End-to-end diagnostic pipeline using Gemini's multimodal vision API to generate structured radiology reports from X-rays, CTs, and MRIs, with DICOM ingestion and human-in-the-loop feedback. *(Gemini API, OpenCV, Streamlit)*

**📊 [Biomedical Data Analysis App](#)**
Natural-language interface letting clinicians query clinical datasets in plain English, powered by Gemini's code-execution for real-time statistical analysis and visualization. *(Gemini API, Pandas, Matplotlib)*

**🩺 [Patient-Specific Coronary Hemodynamics Modeling](#)**
3D patient-specific coronary arterial tree reconstruction with CFD simulation (301K+ elements) and Monte Carlo uncertainty quantification on Windkessel boundary parameters. *(SimVascular, Ansys Fluent, ParaView)*
